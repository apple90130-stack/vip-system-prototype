# 個人 VIP 系統 — 互動原型

這是一個個人化 VIP 會員系統的可點擊原型（HTML prototype），用於展示前台會員介面與後臺管理系統的設計構想。

## 線上展示

部署後可透過 GitHub Pages 直接開啟：

```
https://<你的-github-帳號>.github.io/<repo-名稱>/
```

## 功能總覽

### 會員端（前台）

- **個人首頁**：VIP 進度條（消費金額、曬單次數）、跟團次數、累積消費、積分
- **專屬活動**：依會員已購買商品自動篩選出對應的打卡 / 抽獎活動
- **線上課程**：依會員標籤推薦課程，可點擊「我要報名」
- **開團行事曆**：月曆形式展示近期團購預告，依團型上色
- **打卡專區**：僅顯示已購商品的打卡活動，含個人進度條
- **任務專區**：上傳任務照片（曬單、開箱、心得文）取得積分
- **公告區**：粉絲福利活動公告

### 管理端（後臺）

- **總覽儀表板**：會員 / VIP / 待審任務 / 課程數統計、標籤分布、待辦提醒
- **會員管理**：依標籤一鍵篩選會員列表，顯示消費、跟團、曬單數據
- **標籤管理**：新增、編輯、派發標籤
- **課程管理**：編輯課程內容、查看報名人數、寄送提醒
- **任務審核**：通過或退回會員上傳的任務照片，給予積分
- **公告管理**：新增、刪除前台公告（即時更新）

## 技術說明

- 純單檔 HTML，無需建置工具
- 使用 [Tailwind CSS](https://tailwindcss.com/) 經 CDN 載入
- 使用 [Lucide Icons](https://lucide.dev/) 經 CDN 載入
- 內建模擬資料（會員、商品、課程、任務等）
- 不使用任何後端或資料庫，所有狀態存於記憶體（重整即還原）

## 本機使用

直接雙擊 `index.html` 即可在瀏覽器開啟。

## 部署到 GitHub Pages

1. 將整個資料夾上傳至 GitHub 的 public repo
2. 進入 repo 的 **Settings → Pages**
3. **Source** 選 `Deploy from a branch`
4. **Branch** 選 `main` 與 `/ (root)`，按 **Save**
5. 等 1–2 分鐘，頁面上方會顯示部署網址
6. 將該網址分享給任何人即可使用

## 後續可擴充項目

- 串接真實顧客資料表（消費金額、跟團次數自動同步）
- 標籤條件自動派發（依商品條件）
- LINE OA / Email 自動提醒（課程報名、開課當天）
- 後端資料庫（建議：Node + SQLite / PostgreSQL，可部署於 Zeabur）
- 管理員登入與權限控管（RBAC）
- 任務種類擴充（影片、心得文、推薦好友等）
